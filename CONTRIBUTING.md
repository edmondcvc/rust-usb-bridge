# Contributing / 参与开发

Use the pinned toolchain and `cargo test --locked --workspace`. Run `python3 scripts/check-docs.py` and `python3 scripts/audit-public.py` after staging changes. Keep English/Chinese documents and command examples aligned. Submit a pull request with the behavior changed, tests run and remaining hardware limitations. Do not post credentials or private deployment logs. Do not mark hardware support verified from a build or mock test.

使用固定工具链并执行完整测试；暂存更改后检查双语文档和公开内容。PR 说明行为、验证及硬件限制，不上传身份文件或原始私有日志。新增参数须同步两种语言的说明。

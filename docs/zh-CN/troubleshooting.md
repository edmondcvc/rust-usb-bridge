# 故障处理

[English](../en/troubleshooting.md)

| 现象 | 检查方法 |
|---|---|
| 服务无法启动 | 检查 journal、架构、内核模块和文件权限 |
| 主机状态未知 | 检查电源、网络、地址、SSH／TLS 端口；旧缓存不代表设备空闲 |
| 密码或权限错误 | 确认账户可 SSH 密码登录，且该密码可通过 sudo；不同密码不支持当前快捷授权 |
| 主机指纹改变 | 核对地址和是否重装，不直接删除旧信任绕过检查 |
| Windows 驱动未就绪 | 检查安装日志和重启要求，使用安装器修复 |
| 设备由其他电脑占用 | 请对方主动断开；管理员仅核对指定会话后强制释放 |
| 设备列表没有设备 | 检查线缆、供电、Linux USB 枚举和是否被其他转发软件管理 |
| 关闭后找不到窗口 | 打开任务栏 ^，单击蓝色 USB 托盘图标 |

保留实际报错，不通过清空身份或重装系统来猜测解决问题。导出日志后去除密码、私钥、邀请、主机名和真实地址，再提交 issue。提交系统版本、CPU 架构、内核、程序版本、设备 VID/PID、操作步骤及时间。

安装日志：Linux `/var/log/rust-usb-bridge/`，Windows `C:\ProgramData\RustUsbBridge\logs`。共享失败与主机离线是不同问题。系统启动盘、挂载存储、维护输入设备和 USB hub 默认受保护，不应强行转发。

# Windows 窗口、任务栏与托盘

- 点击主窗口右上角“×”后，窗口最小化并保留在底部任务栏（Dock）。
- 窗口已最小化时，在任务栏图标菜单选择“关闭窗口”，隐藏到右下角系统托盘。
- 点击托盘图标或选择“打开 USB 连接中心”，恢复原窗口。
- 重复双击程序只会恢复已有窗口，不会再开第二个客户端窗口。同一 Windows 会话中，正式 GUI 共用一个实例；示例模式使用独立实例。
- 真正退出仍使用“退出客户端…”及已有的断开确认流程。最小化和隐藏不会断开 USB。
- 托盘初始化失败时保留退出确认，避免窗口隐藏后找不到入口。

单实例限制从本次版本开始生效。更新前已运行的旧版客户端不具备该机制；更新后首次使用应先正常退出旧版客户端。

## 验证记录（2026-10-24）

- Windows GNU 工具链：`cargo test --locked -p bridge-client --lib`，46 项通过。
- 原生 HWND 回归：连续三次验证正常窗口 → 最小化 → 隐藏 → 恢复，隐藏期间窗口没有销毁。
- 子进程回归：连续三次重复启动，第二实例通知原窗口恢复后退出；退出后互斥锁可重新获取。
- 原有托盘消息回归通过；隐藏窗口能由托盘事件立即恢复。
- 发布版示例 GUI：窗口能显示，点击关闭后重复启动恢复同一 HWND；第二进程退出码为 0，仍只有一个示例进程。
- 任务栏菜单与托盘图标的完整鼠标操作链尚未逐项验收；上述原生消息回归不等同于完整人工视觉验收。
- 测试未连接真实 USB 设备，未替换本机正在运行的已安装客户端。

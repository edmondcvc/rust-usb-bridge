# 配对、连接与使用 USB

[English](../en/usage.md) · [安装](installation.md)

以下截图来自本版本的隔离演示模式，顶部示例选择栏在正常安装版中不会出现；地址和设备均为示例。

## 第一次配对

1. 在 **连接 Linux** 中填写可访问的主机 IP／域名、主机账户和密码。界面建议用户名 `operator`，实际账户不同就修改。高级设置中有 SSH 端口（22）和服务端口（3241）。
2. 点击 **连接 Linux**。第一次连接时，把界面显示的 SSH 指纹与 Linux 控制台 `ssh-keygen -lf` 的输出核对。已有主机身份发生变化时，先确认原因。
3. 确认后，程序通过 SSH／sudo 取得授权信息，并为本机申请独立证书。密码仅用于本次操作，不保存在客户端设置中。主机必须已经安装服务。
4. 顶部显示 Linux 已连接，表示可以读取管理状态。对空闲设备点击 **连接**，直到显示 **本机正在使用** 后，再打开原来的设备应用。

## 设备占用与换电脑

一个物理 USB 同时只属于一台电脑，复合接口整体连接。电脑 A、B 可分别使用主机上的不同设备。被其他电脑占用时，优先让对方结束操作并主动断开。**更多 → 管理员强制断开** 需要再次验证 Linux 管理密码，核对具体设备和会话；可能中断对方操作，释放后也不会自动抢接。

存储设备先在 Windows 安全弹出。结束设备操作后，点击对应行的 **断开**。要释放本机全部设备并停止自动连接，点击 **断开 Linux** 并确认。配对保留，其他电脑使用的设备不受影响；主动断开状态在重启软件后仍保留。

## 窗口与托盘

点击 **×** 会隐藏窗口并保持连接。单击右下角 **蓝色 USB 托盘图标** 即可恢复原窗口，图标可能在任务栏 **^** 中。右键图标 → **退出客户端…** 可明确选择保持后台连接退出前台，或断开本机设备后退出。关闭窗口不等于释放设备。

## 添加另一台 Windows

新电脑安装客户端后，可独立重复密码授权。也可以由已配对电脑在设置中创建一次性邀请，保存并在新电脑导入，完成 **添加这台电脑**。邀请 15 分钟有效且只能使用一次，属于临时授权信息，只传给目标电脑，不要上传问题反馈。

高级证书／配对码方式：通过可信渠道取得 `/opt/rust-usb-bridge/public/ca.pem`，在 Linux 执行 `sudo /opt/rust-usb-bridge/usb-bridge-server pair-code --state-dir /var/lib/rust-usb-bridge`，然后在高级配对中提供 CA 和配对码。成功后配对码轮换。公开 CA 不是私钥，但每次部署都应有自己的 CA，发布包不附带通用生产身份。

## 升级、备份与卸载

下载新版本架构对应的 Linux 包，校验后让所有电脑释放设备，再执行安装程序。原身份、配对和共享配置保留，之前的程序与服务单元备份在 `/opt/rust-usb-bridge/backups/时间戳`。恢复之前的程序：`sudo bash /opt/rust-usb-bridge/rollback-linux.sh --backup 时间戳`。不加 `--backup` 时只停止本桥接并恢复它记录的 USB 绑定。卸载：`sudo bash /opt/rust-usb-bridge/uninstall-linux.sh`，私有身份目录保留，方便有意重新安装。

设备释放并停止服务后，可在本地以仅 root 可访问的权限备份 `/var/lib/rust-usb-bridge`。不要上传该归档；只恢复到同一预期主机，不能拿来复制多台机器的身份。Windows 私有状态的备份也需在停止服务后用管理员权限操作。丢失主机私有身份需要重新配对，只换网络地址通常不需要。

Windows 升级前释放本机会话，再运行新版安装器。完整 Windows 包包含两种 Linux 程序，界面内升级器先确认远端架构再选择文件；也可使用架构对应的离线 Linux 包更新。反馈问题时在设置中导出日志，分享前去除私密信息。见[故障处理](troubleshooting.md)。

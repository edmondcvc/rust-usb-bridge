Rust USB Bridge 0.2.0-rc.1 / USB 连接中心预发布版

Standalone source release with matching English/Chinese installation and usage guides, x86_64/aarch64 Linux packages, Windows x64 setup, clean Ubuntu image recipes, CI and integrity manifests. Existing pairing protocol remains version 1. Simplified Chinese UI and single-click tray restore are retained.

独立开源版本，提供中英文安装与使用教程、Linux x86_64／aarch64 包、Windows x64 安装器、纯净 Ubuntu 镜像构建流程及完整性校验。保留协议版本 1、简化中文界面和单击托盘恢复。

This is a prerelease. Real USB acceptance on the public build is pending; generic ARM64, Raspberry Pi 4 and Raspberry Pi 5 physical acceptance is unavailable. VM/mock/CI results do not certify those devices. Image recipes do not imply that every boot image is built or accepted; use only assets actually attached to this release and check their provenance. See the support matrix in both languages.

这是预发布版。公开版本的真实 USB 验收仍待完成，通用 ARM64 和树莓派 4／5 尚无实机验证。虚拟机、模拟设备和 CI 不能代替实机结果。镜像脚本不代表所有镜像均已生成或验收，请只使用实际附件并核对来源记录。

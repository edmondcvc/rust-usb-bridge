Security / 安全报告

Do not open a public issue containing passwords, private keys, pairing codes, invitations or deployment configuration. Use GitHub private vulnerability reporting when enabled; otherwise open an issue asking for a private reporting channel without including the sensitive details. Supported public code currently tracks the latest prerelease; no stable hardware certification is implied.

不要在公开 issue 上传密码、私钥、配对码、邀请或实际部署配置。优先使用仓库启用的私有漏洞报告；若不可用，先发不含敏感细节的联系请求。当前维护最新预发布分支。
